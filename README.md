## About the Project

This is an open-source Android Call SMS testing project designed to demonstrate how automated SMS requests can be handled within an Android application.

### Features

- Open-source Android project
- Simple and easy-to-understand structure
- Can be opened and reviewed in Android Studio
- Suitable for learning and development purposes
